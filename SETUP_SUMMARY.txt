✅ PROJECT STRUCTURE

│   ├── preload.ts                 - Secure IPC bridge (context-isolated)
│   └── services/

│       ├── recordingService.ts    - SoX recording, input device list
│       ├── audioControlService.ts - Mute/restore system audio
│       ├── pasteService.ts        - Clipboard + Ctrl+V injection (libnut)
│       ├── apiService.ts          - Transcription HTTP client
│       ├── settingsService.ts     - Settings persistence (electron-store)
│       ├── settingsMigration.ts   - Built-in vs external default on upgrade
│       ├── modelCatalog.ts        - Curated models, URL/GGML validation
│       ├── modelManager.ts        - Model download, verify, list, delete
│       ├── whisperServer.ts       - whisper.cpp server supervisor
│       ├── serverOutput.ts        - Server log parsing, restart backoff
│       ├── serverPaths.ts         - Server binary resolution
│       ├── serverGate.ts          - Recording gate + status text
│       └── whisperRuntime.ts      - Electron/Node wiring for the above
├── public/index.html              - UI: status line, settings, models manager
├── assets/whisper.ico             - Application icon
├── scripts/fetch-whisper.js       - Dev: fetch pinned whisper.cpp CPU server

├── docs/superpowers/              - Design spec + implementation plan
├── dist/                          - Compiled JavaScript (generated)

✅ KEY FEATURES
1. Built-in whisper.cpp server - bundled, started and supervised by the app;
   localhost only, GPU (Vulkan) with automatic CPU fallback
2. Speech model manager - SHA256-verified downloads from Hugging Face plus
   custom model links; stored in %APPDATA%\whisper-desktop\models
3. Global hotkey (Ctrl+Q) - press to start, press again to stop (5 min cap)
4. Auto-paste - clipboard write, Ctrl+V, then previous clipboard restored
5. Tray integration - status tooltip, Show/Hide, Models…, Exit
6. Settings - server mode, Force CPU, hotkey, microphone, auto-mute,
   external API URL and token
7. External API support - OpenAI Whisper API or any compatible server;
   existing installs keep using their configured endpoint after upgrade

✅ DATA LOCATIONS (%APPDATA%\whisper-desktop\)
  config.json                  - Settings
  models\                      - Downloaded speech models
  recordings\                  - Temporary audio (auto-deleted after 7 days)
  logs\whisper-server.log      - Server output, last 500 lines per run
  whisper-server.pid           - Running server PID (for orphan cleanup)

GETTING STARTED (development):
1. npm install
2. npm run whisper:fetch
3. npm start
4. Open the window from the tray, download a model, wait for "Ready"
5. Press Ctrl+Q, speak, press Ctrl+Q again

RELEASING:
  git tag v1.2.0 && git push origin v1.2.0
  CI lints, tests, builds CPU + Vulkan servers, then publishes a Release.
